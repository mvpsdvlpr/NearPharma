# Política de Privacidad de NearPharma

**Última actualización**: 2 de noviembre de 2025

## 1. Introducción

NearPharma ("nosotros", "nuestra" o "la aplicación") respeta su privacidad y se compromete a proteger sus datos personales. Esta política de privacidad le informará sobre cómo manejamos sus datos personales cuando utiliza nuestra aplicación móvil.

## 2. Información que Recopilamos

### 2.1 Ubicación del Dispositivo
- **Tipo de dato**: Ubicación geográfica aproximada (coordenadas GPS)
- **Propósito**: Para mostrar las farmacias más cercanas a su ubicación actual
- **Base legal**: Consentimiento del usuario (solicitado al usar la función de ubicación)
- **Almacenamiento**: Los datos de ubicación se procesan localmente en su dispositivo y no se almacenan en nuestros servidores

### 2.2 Datos que NO Recopilamos
La aplicación NearPharma **NO** recopila, almacena ni comparte:
- Información personal identificable (nombre, correo electrónico, teléfono)
- Historial de búsquedas
- Datos de navegación
- Información de contacto
- Datos de salud o médicos
- Información financiera o de pago

## 3. Cómo Utilizamos su Información

La ubicación geográfica se utiliza exclusivamente para:
- Ordenar las farmacias por proximidad a su ubicación actual
- Mejorar la experiencia de usuario mostrando resultados relevantes
- Permitir la navegación hacia farmacias seleccionadas

## 4. Fuente de Datos de Farmacias

Los datos de farmacias (nombres, direcciones, horarios, turnos) son obtenidos directamente de:
- **MINSAL** (Ministerio de Salud de Chile)
- API pública: https://seremienlinea.minsal.cl/asdigital/mfarmacias/

NearPharma actúa como intermediario para facilitar el acceso a esta información pública y no modifica ni almacena estos datos.

## 5. Permisos de la Aplicación

### 5.1 Permiso de Ubicación
- **Propósito**: Determinar su posición actual para mostrar farmacias cercanas
- **Opcional**: Puede usar la aplicación sin otorgar este permiso; en tal caso, deberá buscar farmacias manualmente por región y comuna
- **Revocación**: Puede revocar este permiso en cualquier momento desde la configuración de su dispositivo

### 5.2 Acceso a Internet
- **Propósito**: Consultar la información actualizada de farmacias desde la API de MINSAL
- **Necesario**: Este permiso es esencial para el funcionamiento de la aplicación

## 6. Almacenamiento y Seguridad de Datos

- **Almacenamiento local**: Solo se almacenan temporalmente en su dispositivo los datos necesarios para el funcionamiento de la aplicación (cache de búsquedas recientes)
- **Sin servidores propios**: NearPharma no opera servidores que almacenen sus datos personales
- **Sin registro de usuario**: No requiere crear cuenta ni proporcionar información personal

## 7. Compartir Datos con Terceros

### 7.1 Servicios de Terceros Utilizados

**API de MINSAL**
- Las consultas de farmacias se realizan directamente a la API pública de MINSAL
- MINSAL puede tener su propia política de privacidad para el uso de su API

**Google Maps / Mapas del dispositivo**
- Al usar la función "Cómo llegar", se abrirá la aplicación de mapas de su dispositivo
- Estas aplicaciones tienen sus propias políticas de privacidad

### 7.2 No Vendemos Datos
NearPharma **NUNCA** vende, alquila o comparte sus datos personales con terceros con fines comerciales o publicitarios.

## 8. Privacidad de Menores

NearPharma no está dirigida a menores de 13 años y no recopilamos intencionalmente información personal de menores. Si es padre o tutor y cree que su hijo nos ha proporcionado información personal, contáctenos para eliminarla.

## 9. Sus Derechos

Usted tiene derecho a:
- **Revocar permisos**: Puede desactivar el acceso a la ubicación en cualquier momento desde la configuración de su dispositivo
- **Eliminar datos locales**: Puede borrar el caché de la aplicación o desinstalarla para eliminar todos los datos almacenados localmente
- **Solicitar información**: Puede contactarnos para cualquier pregunta sobre sus datos

## 10. Cookies y Tecnologías de Seguimiento

NearPharma **NO** utiliza:
- Cookies
- Píxeles de seguimiento
- Tecnologías de análisis de terceros
- Herramientas de publicidad

## 11. Cambios a esta Política de Privacidad

Podemos actualizar nuestra política de privacidad ocasionalmente. Le notificaremos cualquier cambio publicando la nueva política en esta página y actualizando la fecha de "Última actualización".

Se le recomienda revisar esta política periódicamente para estar informado de cualquier cambio.

## 12. Legislación Aplicable

Esta política de privacidad se rige por las leyes de Chile, incluyendo:
- Ley N° 19.628 sobre Protección de la Vida Privada
- Normativas aplicables de protección de datos personales
